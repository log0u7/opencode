### Changed

- compaction: `buffer` 2000 -> `"10%"` (percentage form, v2.2.5 #60647). Fix for the recurring `Compaction summary reached the output token limit` crash on long sessions (`999.4K in · 2.0K out` toast): the compaction summary output budget = gap between the trigger point and the context window, clamped [1024, 32000] - with the old 2000-token buffer the summary request got exactly 2000 output tokens and always truncated (anomalyco/opencode #54820, confirmed by the maintainer); at relaunch the server `drain` re-runs the failed compaction, so the session bricked itself in a loop. Percentage form scales across the fleet's mixed windows (30K glm-4.7-flash, 94K qwen3.5, 1M glm-5.3-flash) where a fixed integer would starve small models; 10% of 1M = 100K trigger headroom, summary budget reaches the 32000 cap. Recovery for an already-bricked session: relaunch (drain retries with the new 32K budget) or manual `/compact`
- opencode.json + AGENTS.md: hard anti-idle-wait enforcement - 9 new shell permission deny globs matching inline `sleep` at every practical position in the command string: leading (`sleep*`), and after each shell separator with and without space (`*;sleep*`/`*; sleep*`, `*&&sleep*`/`*&& sleep*`, `*||sleep*`/`*|| sleep*`, `*&sleep*`/`*& sleep*`), triggered by agents blocking the session with wait-then-check chains (`cd wt/x && sleep 90; ls static/images/og/en | wc -l; pgrep -f og-cards.mjs >/dev/null && echo STILL_RUNNING || echo DONE`: 90s foreground sleep per cycle, 3 min wasted); AGENTS.md `## Parallelism and patience` documents the enforcement, the real offender, the canonical replacements (ONE blocking command that finishes the work then reports, or a `background=true` run read at the exit notification) and that instant status checks (`pgrep`, `test -f`, `ls`) stay legal. Verified live same-session (permissions hot-reload, no restart needed): `echo probe; sleep 1` rejected, `grep -c sleep AGENTS.md` still passes. First pattern draft used a bare-space `* sleep*` glob: reverted after a live false positive (it blocked `grep -c sleep file`, where the space before the argument is just argument separation); separator-anchored variants replaced it. Scope notes: globs match the command string only, so `sleep` inside script FILES stays allowed (intended home for retry/backoff); CLI flags like `--sleep` unmatched; `watch -n`/`timeout`/`read -t` substitutes covered by prose only; `sleep` on its own line inside a multi-line command block not covered by any glob (known gap, prose covers)
